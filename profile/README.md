## What we build

| Area | What it covers |
|---|---|
| **Shipments** | Order intake, labelling, tracking, proof of delivery |
| **Fleet** | Vehicles, drivers, routing, telematics |
| **Warehouse** | Inventory, picking, packing, stock movements |
| **Integrations** | Carriers, customs, ERP and marketplace connectors |
| **Platform** | Shared libraries, auth, observability, infrastructure |

## How we work

- **`main` is always deployable.** Every change lands through a pull request.
- **Review is required.** No direct pushes, no force-pushes, no self-merges.
- **CI gates the merge.** Lint, tests, build and security scans must pass.
- **Conventional Commits.** Commit and PR titles follow `type(scope): subject`.
- **Secrets never touch the repo.** Push protection and secret scanning are on.

New to a repository here? Start with its `README.md`, then
[`CONTRIBUTING.md`](https://github.com/Mtl-Logistics/.github/blob/main/CONTRIBUTING.md).
